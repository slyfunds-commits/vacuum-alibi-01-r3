One line, 200 characters or fewer: the excuse a robot vacuum gives for missing a spot. The vacuum reported the spot to itself in March — the case is still open, and the vacuum is the suspect.

## Run it

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` and asserts the file holds exactly the line.
